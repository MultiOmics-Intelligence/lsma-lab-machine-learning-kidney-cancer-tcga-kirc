Methods

Assembled from what each completed stage recorded. Check it against the parameter tables below before using it in a write-up.

A model was trained to tell 'Stage IV' from 'Stage I' (22 and 93 samples) from 17,316 features (gene expression, log2(counts per million + 1)). Restriction: none.

29 samples (25%) were set aside as a test set (stratified by class). On the remaining 86, Logistic regression (L2), Logistic regression (lasso), Logistic regression (elastic net), Random forest, Support vector machine (linear), Histogram gradient boosting were compared by 5-fold, repeated 2 times, on the training samples; in every fold, the 200 features with the largest F statistic, chosen inside every fold, features were scaled, and settings tuned by an inner 3-fold cross-validation (nested). The chosen model was Random forest (cross-validated ROC AUC 0.8274 +/- 0.1554; 100 label permutations, p = 0.0099).

On the test set the model reached a ROC AUC of 0.8841 (0.72 to 1.00 (95%, bootstrap)), sensitivity 0.3333 and specificity 0.9565 at a probability threshold of 0.5. The model was validated on a held-out part of the same dataset; a second, independent dataset is the stronger test and is not available here.

Feature importance: permutation importance on the test samples (20 shuffles per feature), for the 200 features of the Random forest model.

Random seed: 42. Software: python 3.12.16; joblib 1.6.0; lifelines 0.30.3; numpy 2.5.4; pandas 2.3.3; scikit-learn 1.9.1; scipy 1.18.1.

Analyses were run on the LSMA Analysis Lab (workflow 'machine-learning' version 1.0.0).

Stage 2 of 4

Training and model choice Statistically supported

A quarter of the samples are put aside as the test set and not touched. On the rest, each model is trained and scored several times by cross-validation: the training samples are cut into five parts, the model learns from four and is scored on the fifth, in turn. Choosing features, scaling them and tuning the model's settings are all repeated inside every round. The best model is then fitted on all training samples. Finally the labels are shuffled a hundred times and everything is repeated, to see what score pure chance produces.

Note. Random forest scored highest, but 5 other model(s) cannot be told apart from it on these folds (Logistic regression (L2), Logistic regression (lasso), Logistic regression (elastic net)). Picking the top of a table like this is usually picking noise; prefer the simplest model among those that cannot be separated.
Note. The best two models differ by less than the spread between folds. The choice between them is not meaningful.

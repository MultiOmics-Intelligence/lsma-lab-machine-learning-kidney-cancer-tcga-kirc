Methods

Assembled from what each completed stage recorded. Check it against the parameter tables below before using it in a write-up.

A model was trained to predict time to the event ('vital_status' = Dead; 200 patients, 82 events) from 17,316 features (gene expression, log2(counts per million + 1)). Restriction: none.

50 patients were set aside as a test set. On the remaining 150 (61 events), a Cox regression with elastic-net penalty (lifelines), on the most variable features of the training patients was fitted on 50 features; the penalty (0.1) was chosen by 5-fold on the training patients (concordance index 0.6785 +/- 0.0837).

On the test set the concordance index was 0.6592 (0.53 to 0.78 (95%, bootstrap)); predicted high- and low-risk patients were compared with the log-rank test (p = 0.03005). The model was validated on a held-out part of the same dataset; a second, independent cohort is the stronger test and is not available here.

Feature importance: weights of the penalised Cox model.

Random seed: 42. Software: python 3.12.16; joblib 1.6.0; lifelines 0.30.3; numpy 2.5.4; pandas 2.3.3; scikit-learn 1.9.1; scipy 1.18.1.

Analyses were run on the LSMA Analysis Lab (workflow 'machine-learning' version 1.0.0).

Stage 2 of 4

Training and model choice Statistically supported

A quarter of the samples are put aside as the test set and not touched. On the rest, each model is trained and scored several times by cross-validation: the training samples are cut into five parts, the model learns from four and is scored on the fifth, in turn. Choosing features, scaling them and tuning the model's settings are all repeated inside every round. The best model is then fitted on all training samples. Finally the labels are shuffled a hundred times and everything is repeated, to see what score pure chance produces.

Read the box plot: overlapping boxes mean the models are equivalent. Read the chance test: the real score should sit well outside the scores obtained with shuffled labels. Then look at how stable the selected features are; a signature that changes with every fold is not a signature.

How to interpret this stage

Compare the test score with the cross-validation score: a much lower test score means overfitting. Look at the interval rather than the single number; with 20 test samples it is wide. Sensitivity and specificity depend on the threshold of 0.5, which is a convention; the ROC curve shows every threshold.
